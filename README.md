# 🏥 Professional Healthcare Analytics Dashboard

A professional **Healthcare Analytics Dashboard** built using **Python, Pandas, and Matplotlib**. This dashboard provides insights into patient admissions, recovery rates, emergency cases, hospital revenue, department performance, and patient satisfaction through KPI cards and interactive visualizations.

---

## 📊 Dashboard Features

- 👨‍⚕️ Total Patients KPI
- 🏥 Total Admissions KPI
- ❤️ Recovery Rate KPI
- 🚑 Emergency Cases KPI
- 💰 Average Revenue KPI
- ⭐ Patient Satisfaction KPI
- 📈 Monthly Patient Visits
- 💵 Hospital Revenue Trend
- 🏥 Department-wise Patient Analysis
- ❤️ Admissions vs Recoveries
- 👶 Age Group Analysis
- 🦠 Disease Distribution
- 👨 Gender Distribution
- 🛏️ Bed Occupancy Rate
- 👩‍⚕️ Doctor Performance Analysis
- ⭐ Patient Satisfaction Trend
- 🌙 Professional Dark Theme
